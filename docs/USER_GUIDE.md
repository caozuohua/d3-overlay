## 1. 安装指南

### 1.1 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 64-bit 或更高版本 |
| Python | 3.10+ (如果从源码运行) |
| 游戏模式 | 窗口化 / 无边框窗口化（推荐） |
| 内存 | 200MB 可用 |
| 磁盘 | 50MB |

### 1.2 安装方式

#### 方式一：EXE 安装包（推荐）

1. 从发布页下载最新版本 `D3OA-vX.X.X-setup.exe`
2. 双击运行安装程序
3. 按提示完成安装
4. 桌面会出现 D3OA 快捷方式

#### 方式二：从源码运行

```bash
# 1. 克隆项目
git clone https://github.com/yourname/d3-overlay.git
cd d3-overlay

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 编译 C 扩展（可选，纯 Python 也能运行）
cd src
python setup.py build_ext --inplace

# 4. 启动
python src/main.py
```

### 1.3 游戏设置要求

⚠️ **重要**：请在 Diablo 3 中进行以下设置以获得最佳效果：

1. **显示模式** → 选择「**无边框窗口化**」（推荐）或「窗口化」
   - 路径：选项 → 显示 → 显示模式
2. **分辨率** → 建议与桌面分辨率一致
3. **V-Sync** → 建议关闭（减少输入延迟）

> 独占全屏模式下叠加窗口会被游戏覆盖，这是 Windows 系统的限制。

## 4. 插件使用

### 4.1 秘境计时器 (Timer)

**功能**：记录大秘境/小秘境的通关时间。

| 显示内容 | 说明 |
|----------|------|
| 当前用时 | 从进入秘境开始计时 |
| 分段用时 | 每层进度的时间 |
| 最佳记录 | 历史最快通关时间 |

**操作**：
- 按 `F9` 开始/停止计时
- 按 `Shift+F9` 重置计时器

### 4.2 构筑信息 (BuildInfo)

**功能**：通过 Blizzard API 获取当前角色的装备和技能构筑。

**显示内容**：
- 角色名称与职业
- 当前装备套装
- 主动技能与符文
- 巅峰等级

**要求**：需要在设置中填写 BattleTag。

### 4.3 复仇怪追踪 (Nemesis)

**功能**：追踪复仇怪物（Nemesis）的状态。

**显示内容**：
- 复仇怪是否已击杀
- 下次可能出现的时间
- 击杀奖励提示

### 4.4 秘境进度 (RiftInfo)

**功能**：显示当前秘境的进度信息。

**显示内容**：
- 进度百分比
- 进度球数量
- Boss 出现倒计时（估算）

## 6. 自动点击器 (AutoClicker)

### 6.1 功能说明

自动点击器可以帮助你自动完成 Diablo 3 中的简单重复操作：

- **装备拾取**: 连续点击地面装备自动拾取
- **装备鉴定**: 连续点击凯恩之书自动鉴定
- **装备分解**: 连续点击分解 NPC 自动分解
- **血岩赌博**: 连续点击赌博商人自动赌博

### 6.2 使用方法

1. 将鼠标移动到需要点击的位置（如地面装备上）
2. 按下 `F7` 启动自动点击
3. 再次按 `F7` 停止
4. 按住 `Shift` 键可临时暂停点击

### 6.3 配置选项

在 `config.json` 的 `autoclicker` 部分配置：

```json
{
  "autoclicker": {
    "enabled": true,
    "interval_ms": 100,
    "max_clicks": 0,
    "foreground_only": true,
    "click_button": "left",
    "pause_on_key": true,
    "pause_key": "SHIFT"
  }
}
```

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `enabled` | 是否启用自动点击功能 | `true` |
| `interval_ms` | 点击间隔（毫秒），范围 20-5000 | `100` |
| `max_clicks` | 最大点击次数，0=无限制 | `0` |
| `foreground_only` | 仅在游戏前台时点击 | `true` |
| `click_button` | 点击按钮: left/right/middle | `left` |
| `pause_on_key` | 按住暂停键时暂停点击 | `true` |
| `pause_key` | 暂停键: SHIFT/CTRL/ALT/SPACE | `SHIFT` |

### 6.4 安全说明

- 使用 Win32 `SendInput` API，与物理鼠标点击等效
- 不读写游戏内存，不注入 DLL
- 仅在游戏窗口前台时生效（默认配置）
- 可随时按 `F7` 停止，或按住 `Shift` 暂停

⚠️ **注意事项**：
- 长时间无人值守的自动化可能违反游戏 EULA
- 建议仅在需要时开启，完成后立即关闭
- D3OA 对使用本功能产生的后果不承担责任

## 7. 高级设置

### 6.1 开启 OCR 功能

OCR 功能可以从游戏截图中识别文字信息（如物品属性）：

1. 安装 Tesseract OCR：
   ```bash
   # 下载安装包: https://github.com/tesseract-ocr/tesseract
   # 安装中文语言包
   ```
2. 在 `config.json` 中设置 `"ocr_enabled": true`
3. 按 `Ctrl+Shift+O` 触发截图 OCR

### 6.2 性能调优

```json
{
  "performance": {
    "target_fps": 30,        // 叠加层帧率（越高 CPU 占用越大）
    "render_quality": "medium", // low / medium / high
    "cache_size_mb": 50,     // API 数据缓存大小
    "log_poll_interval": 1.0 // 日志轮询间隔（秒）
  }
}
```

### 6.3 多显示器支持

```json
{
  "overlay": {
    "monitor": 0,           // 0 = 主显示器, 1 = 副显示器
    "auto_detect_monitor": true // 自动检测游戏所在的显示器
  }
}
```

## 7. 故障排除

### Q: 叠加层不显示

1. 确认游戏使用「无边框窗口化」或「窗口化」模式
2. 检查 `F8` 是否隐藏了叠加层
3. 确认 D3OA 进程正在运行（系统托盘）
4. 尝试以管理员身份运行 D3OA

### Q: 叠加层位置不正确

1. 检查 `config.json` 中的 `position` 设置
2. 如果游戏窗口移动后叠加层没跟随，按 `F10` 刷新
3. 多显示器用户检查 `monitor` 设置

### Q: API 数据不显示

1. 确认 BattleTag 填写正确（格式：名字#数字）
2. 确认角色设置为「公开档案」（游戏内设置）
3. 检查网络连接
4. 确认 API 服务可用（状态页: status.blizzard.com）

### Q: CPU 占用过高

1. 降低 `target_fps` 到 15 或 20
2. 设置 `render_quality` 为 `low`
3. 关闭不需要的插件
4. 关闭 OCR 功能

### Q: 热键不响应

1. 确认没有其他程序占用相同热键
2. 以管理员身份运行 D3OA（某些热键需要提升权限）
3. 检查 `config.json` 中的热键配置

### Q: Windows 安全软件拦截（创建窗口失败）

D3OA 使用标准 Win32 API 创建透明叠加窗口（`CreateWindowExW` + `WS_EX_LAYERED`）。
部分安全软件（如 360、火绒、卡巴斯基）可能将此行为标记为可疑。

**症状：**
- 启动后提示「叠加窗口创建失败」
- 控制台显示 `GetLastError=5`（访问被拒绝）
- 程序被安全软件隔离或阻止运行

**解决方案：**

1. **将 D3OA 添加到安全软件白名单**
   - 360：安全卫士 → 信任区 → 添加文件/目录
   - 火绒：设置 → 允许列表 → 添加程序路径
   - 卡巴斯基：设置 → 威胁和排除 → 排除项 → 添加
   - Windows Defender：设置 → 病毒和威胁防护 → 排除项 → 添加

2. **确保 d3oa.manifest 文件存在**
   - manifest 文件声明了应用的安全属性和 DPI 感知
   - 文件必须与 EXE 在同一目录
   - 如果丢失，从项目根目录重新复制

3. **首次以管理员身份运行（仅一次）**
   - 右键 D3OA.exe → 以管理员身份运行
   - 首次运行后，后续可以普通权限运行
   - 这仅用于完成 Windows 对新应用的信任注册

4. **关闭冲突的 overlay 工具**
   - Discord Overlay（Discord 设置 → Game Overlay → 关闭）
   - Xbox Game Bar（Windows 设置 → 游戏 → Xbox Game Bar → 关闭）
   - GeForce Experience Overlay（Alt+Z → 设置 → 关闭 HUD）
   - Steam Overlay（Steam 设置 → 游戏内 → 关闭）

### Q: 高分辨率屏幕模糊

**症状：**
- 界面文字和图形模糊
- 叠加层位置偏移

**原因：**
Windows DPI 缩放会导致非感知应用被自动缩放，造成模糊。

**解决方案：**

1. **确保 d3oa.manifest 文件存在**
   - manifest 中声明了 `PerMonitorV2` DPI 感知
   - 这是最可靠的解决方案

2. **手动设置 EXE 兼容性（备选方案）**
   - 右键 D3OA.exe → 属性 → 兼容性
   - 勾选「替代高 DPI 缩放行为」
   - 缩放执行选择「应用程序」

3. **Python 直接运行时**
   - D3OA 已在代码中自动设置 DPI 感知
   - 如果仍然模糊，检查 Python 版本（需要 3.10+）

### Q: Windows 防火墙拦截网络请求

**症状：**
- API 数据无法获取
- 控制台显示网络超时

**说明：**
D3OA 会向 Blizzard API（`us.api.blizzard.com` 或 `gateway.battlenet.com.cn`）发起 HTTPS 请求。
Windows 防火墙默认不阻止出站连接，但某些企业/校园网络环境可能有额外限制。

**解决方案：**

1. **Windows 防火墙设置**
   - 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
   - 找到 python.exe 或 d3oa.exe，勾选「专用」和「公用」
   - 或者创建出站规则允许 HTTPS (443) 连接

2. **企业/校园网络**
   - 联系网络管理员，放行到 `*.api.blizzard.com` 和 `*.battlenet.com.cn` 的 HTTPS 连接
   - 或使用允许访问外网的代理

3. **关闭 API 功能**
   - 如果不需要构筑信息展示，可以在 config.json 中禁用 build_info 插件
   - 不配置 BattleTag 即可避免 API 调用

### Q: 全局热键与系统冲突

**症状：**
- F8/F9/F10/F11 被其他程序占用
- 按下快捷键后没有反应

**解决方案：**

1. **修改热键配置**
   ```json
   {
     "hotkeys": {
       "toggle_overlay": "Ctrl+F8",
       "toggle_timer": "Ctrl+F9",
       "cycle_layout": "Ctrl+F10",
       "settings": "Ctrl+F11"
     }
   }
   ```

2. **常见冲突程序**
   - Visual Studio：F8 查找下一个
   - Eclipse：F8 调试继续
   - IntelliJ：F9 恢复程序
   - Steam：F12 截图
   - 解决方案：为 D3OA 添加修饰键（如 Ctrl+Shift+F8）

## 8. 安全说明

### ✅ D3OA 的安全保证

| 安全项 | 说明 |
|--------|------|
| 无内存读写 | 不读取、不写入游戏进程的任何内存 |
| 无 DLL 注入 | 不向游戏进程注入任何动态链接库 |
| 无文件修改 | 不修改游戏目录下的任何文件 |
| 无进程 Hook | 不拦截或修改任何 API 调用 |
| 独立进程 | D3OA 作为独立窗口运行，与游戏进程完全隔离 |

### 📋 使用的合法技术

- **透明窗口叠加** — 与 OBS、Discord Overlay 相同的技术
- **公开 API 查询** — 使用暴雪公开的 Web API
- **日志文件读取** — 只读取游戏自动生成的日志
- **窗口截图捕获** — 与 Windows 截图工具原理一致

### ⚠️ 注意事项

- 本工具仅供个人学习和游戏体验增强使用
- 请遵守暴雪的《最终用户许可协议》(EULA)
- 建议在使用前了解游戏社区规则
- 本工具不提供任何自动化游戏操作功能
