## 1. 安装指南

### 1.1 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 64-bit 或更高版本 |
| Python | 3.10+ (如果从源码运行) |
| 游戏模式 | 窗口化 / 无边框窗口化（推荐） |
| 内存 | 200MB 可用 |
| 磁盘 | 50MB |

### 1.2 安装方式

#### 方式一：EXE 安装包（推荐）

1. 从发布页下载最新版本 `D3OA-vX.X.X-setup.exe`
2. 双击运行安装程序
3. 按提示完成安装
4. 桌面会出现 D3OA 快捷方式

#### 方式二：从源码运行

```bash
# 1. 克隆项目
git clone https://github.com/yourname/d3-overlay.git
cd d3-overlay

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 编译 C 扩展（可选，纯 Python 也能运行）
cd src
python setup.py build_ext --inplace

# 4. 启动
python src/main.py
```

### 1.3 游戏设置要求

⚠️ **重要**：请在 Diablo 3 中进行以下设置以获得最佳效果：

1. **显示模式** → 选择「**无边框窗口化**」（推荐）或「窗口化」
   - 路径：选项 → 显示 → 显示模式
2. **分辨率** → 建议与桌面分辨率一致
3. **V-Sync** → 建议关闭（减少输入延迟）

> 独占全屏模式下叠加窗口会被游戏覆盖，这是 Windows 系统的限制。

### 2.2 手动编辑配置

> ⚠️ 说明：当前**没有**图形化配置向导（USER_GUIDE §1.1 的向导图仅为规划示意），
> 也无系统托盘菜单（§3.2）。配置通过编辑 JSON 完成。

配置文件位于：`~/.d3oa/config.json`（即 `%USERPROFILE%\.d3oa\config.json`）

```json
{
  "overlay": {
    "opacity": 0.85,
    "position": "top-right",
    "font_size": 14,
    "theme": "dark",
    "click_through": true
  },
  "data": {
    "battle_tag": "YourName#1234",
    "region": "us",
    "ocr_enabled": false
  },
  "plugins": {
    "timer": { "enabled": true },
    "build_info": { "enabled": true }
  }
}
```

## 4. 插件使用

### 4.1 秘境计时器 (Timer)

**功能**：记录大秘境/小秘境的通关时间。

| 显示内容 | 说明 |
|----------|------|
| 当前用时 | 从进入秘境开始计时 |
| 分段用时 | 每层进度的时间 |
| 最佳记录 | 历史最快通关时间 |

**操作**：
- 按 `F9` 开始/停止计时
- 按 `Shift+F9` 重置计时器

### 4.2 构筑信息 (BuildInfo)

**功能**：通过 Blizzard API 获取当前角色的装备和技能构筑。

**显示内容**：
- 角色名称与职业
- 当前装备套装
- 主动技能与符文
- 巅峰等级

**要求**：需要在设置中填写 BattleTag。

### 4.3 复仇怪追踪 (Nemesis)

**功能**：追踪复仇怪物（Nemesis）的状态。

**显示内容**：
- 复仇怪是否已击杀
- 下次可能出现的时间
- 击杀奖励提示

### 4.4 秘境进度 (RiftInfo)

**功能**：显示当前秘境的进度信息。

**显示内容**：
- 进度百分比
- 进度球数量
- Boss 出现倒计时（估算）

### 6.2 性能调优

```json
{
  "performance": {
    "target_fps": 30,        // 叠加层帧率（越高 CPU 占用越大）
    "render_quality": "medium", // low / medium / high
    "cache_size_mb": 50,     // API 数据缓存大小
    "log_poll_interval": 1.0 // 日志轮询间隔（秒）
  }
}
```

### 6.3 多显示器支持

```json
{
  "overlay": {
    "monitor": 0,           // 0 = 主显示器, 1 = 副显示器
    "auto_detect_monitor": true // 自动检测游戏所在的显示器
  }
}
```

## 7. 故障排除

### Q: 叠加层不显示

1. 确认游戏使用「无边框窗口化」或「窗口化」模式
2. 检查 `F8` 是否隐藏了叠加层
3. 确认 D3OA 进程正在运行（系统托盘）
4. 尝试以管理员身份运行 D3OA

### Q: 叠加层位置不正确

1. 检查 `config.json` 中的 `position` 设置
2. 如果游戏窗口移动后叠加层没跟随，按 `F10` 刷新
3. 多显示器用户检查 `monitor` 设置

### Q: API 数据不显示

1. 确认 BattleTag 填写正确（格式：名字#数字）
2. 确认角色设置为「公开档案」（游戏内设置）
3. 检查网络连接
4. 确认 API 服务可用（状态页: status.blizzard.com）

### Q: CPU 占用过高

1. 降低 `target_fps` 到 15 或 20
2. 设置 `render_quality` 为 `low`
3. 关闭不需要的插件
4. 关闭 OCR 功能

### Q: 热键不响应

1. 确认没有其他程序占用相同热键
2. 以管理员身份运行 D3OA（某些热键需要提升权限）
3. 检查 `config.json` 中的热键配置

## 8. 安全说明

### ✅ D3OA 的安全保证

| 安全项 | 说明 |
|--------|------|
| 无内存读写 | 不读取、不写入游戏进程的任何内存 |
| 无 DLL 注入 | 不向游戏进程注入任何动态链接库 |
| 无文件修改 | 不修改游戏目录下的任何文件 |
| 无进程 Hook | 不拦截或修改任何 API 调用 |
| 独立进程 | D3OA 作为独立窗口运行，与游戏进程完全隔离 |

### 📋 使用的合法技术

- **透明窗口叠加** — 与 OBS、Discord Overlay 相同的技术
- **公开 API 查询** — 使用暴雪公开的 Web API
- **日志文件读取** — 只读取游戏自动生成的日志
- **窗口截图捕获** — 与 Windows 截图工具原理一致

### ⚠️ 注意事项

- 本工具仅供个人学习和游戏体验增强使用
- 请遵守暴雪的《最终用户许可协议》(EULA)
- 建议在使用前了解游戏社区规则
- 本工具不提供任何自动化游戏操作功能
